# Hubert #28 i #30 — wznowienie oraz domyślne wyjście dźwięku

Stan: 22.11.2026. Kandydat kodu po alpha.512 w gałęzi `codex/alpha512-update-candidate-20261122`. Zgłoszenie #28 odpowiada PR #29, a #30 odpowiada PR #31. Autor obu poprawek: Hubert (`cinkciarzpl`). Nie jest to instalacja ani wydanie.

## Zachowanie widoczne dla użytkownika

- Po krótkiej pauzie w YouTube wznowienie na przykład przy szybkości 2x powinno kontynuować istniejący strumień, jeśli pozycja odtwarzania pozostała blisko miejsca pauzy. Pozwala to uniknąć zbędnego ponownego ustawiania dekodera i chwilowego zacięcia. Ręczne przeskoczenie pozycji nadal używa zwykłego wznowienia z szukaniem.
- Sesje obsługiwane przez LiteHost powinny podążać za zmianą domyślnego wyjścia dźwięku Windows, jeśli użytkownik nie wybrał ręcznie konkretnego urządzenia. Przy zmianie wyjścia host przełącza odtwarzanie bez ponownego uruchamiania dekodera; dotyczy to także radia. Ręcznie wybrane urządzenie zachowuje pierwszeństwo.
- Spotify działa w osobnym procesie i nie jest objęte podążaniem za domyślnym wyjściem z PR #31. Powrót do ręcznie wskazanego urządzenia po jego niedostępności nie jest automatyczny.
