# AMC Test — poprawki Biblioteki podcastów

- Po usunięciu podcastu lub odcinka z Biblioteki AMC zachowuje położenie na liście i wskazuje sąsiedni element.
- Dodanie podcastu z wyszukiwarki nie przenosi zaznaczenia na początek Biblioteki.
- Potwierdzenie usunięcia odcinka pada po odświeżeniu listy. Zmiana Biblioteki z wyników wyszukiwania ma czytelny komunikat postępu.

TIDAL nadal pokazuje po 150 pozycji na stronę. `Ctrl+F` umożliwia szukanie w pełnej pobranej kolekcji oraz katalogu usługi.
