# AMC Test — zachowanie pauzy po aktualizacji

- AMC Test nie uruchamia sam wstrzymanej stacji po aktualizacji i ponownym starcie.
- Materiał, który rzeczywiście grał przed zamknięciem przez aktualizator, nadal może zostać przywrócony.

Pozostałe zgłoszenia dotyczące zapowiedzi utworów w innych sesjach, menu kontekstowego i skrótu `Shift+Enter` są zapisane do następnych poprawek; nie są częścią tego wydania.
