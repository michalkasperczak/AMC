# AMC Test alpha.533 — szkic instrukcji i listy zmian

Szkic z 27.11.2026 do korekty i zatwierdzenia przez Michała. Nie jest automatycznie publikowany jako instrukcja użytkownika.

## Instrukcja

W Plikach, Podcastach lub Radiu Archiwiście zaznacz odtwarzalną pozycję i naciśnij `Shift+Enter`. Następne wywołania dopisują pozycje w kolejności wyboru po aktualnie grającym materiale. Powtórzenie nie usuwa wpisu. `Ctrl+Shift+Enter` dodaje lub usuwa z tego bloku; `Ctrl+Shift+Q` przełącza zwykłą kolejkę. Polecenia można znaleźć w menu, pomocy `Ctrl+F1`, pełnej pomocy klawiaturowej i palecie `Ctrl+Shift+K`.

## Lista zmian

- `Shift+Enter` jednorazowo dodaje jako następne bez przerwania bieżącego odtwarzania.
- Kilka zaznaczonych materiałów i kilka kolejnych gestów zachowuje kolejność.
- Wyniki wyszukiwania pozostają otwarte po użyciu skrótu.
- HEOS, Apple Music, TIDAL, Spotify i kolejki urządzeń nie otrzymują gestu w tym wydaniu.

Żywy odbiór NVDA i głośnik HEOS nie są potwierdzone. Instalator Test ma powstać w GitHub Actions z dokładnego commitu; numer runu, wydanie i suma zostaną wpisane po weryfikacji.
