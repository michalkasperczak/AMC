# Wyniki testów AMC 0.1.0-alpha.71

Możesz opisać testy całkowicie po swojemu. Nie trzeba przy każdym zadaniu wpisywać wariantu „OK” albo „błąd”. Najbardziej pomagają: użyty skrót, miejsce w programie, wypowiedź NVDA i zachowanie fokusu.

Wersja: `0.1.0-alpha.71`

Zakres: kolejność zakładek według czasu w materiale, grupowanie wielu materiałów, fokus po Enterze, powrót Escape i regresja nazwanych zakładek.
