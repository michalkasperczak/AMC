# AMC 0.1.0-alpha.298 — nieudane nagranie z harmonogramu

Instrukcja: wykonaj możliwe punkty i dopisz uwagi po dwukropku.

1. Utwórz krótki plan dla stacji z celowo nieprawidłowym lub niedostępnym adresem. Po nieudanej próbie AMC powinien oznajmić nazwę stacji oraz przyczynę: 

2. Jeżeli podczas próby aktywne było inne okno, po powrocie do AMC program powinien ponownie podać nieudane nagranie i skrót Ctrl+Shift+H: 

3. Otwórz Ctrl+Shift+H. Przy harmonogramie powinna pozostać data i treść ostatniego błędu: 

4. Nieudany plan jednorazowy powinien pozostać na liście jako wyłączony. Plan cykliczny powinien zachować następny termin: 

5. Prawidłowe nagranie powinno nadal kończyć się i dzielić klawiszem T bez zmiany końcowej godziny harmonogramu:
