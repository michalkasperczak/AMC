# Wyniki testów AMC 0.1.0-alpha.70

Możesz opisać testy całkowicie po swojemu. Nie trzeba przy każdym zadaniu wpisywać wariantu „OK” albo „błąd”. Najbardziej pomagają: użyty skrót, miejsce w programie, wypowiedź NVDA i zachowanie fokusu.

Wersja: `0.1.0-alpha.70`

Zakres: `Ctrl+Shift+B`, dostępne pole nazwy, nadawanie nazwy szybkiej zakładce, lista `Ctrl+B`, nawigacja, wyciszenie i trwałość.
